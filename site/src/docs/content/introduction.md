# Gond Agent

Gond Agent is a self-hosted coding workspace. Describe a task on a GitHub repository, let an isolated worker work on it, and review the resulting pull request. Every account has all features.

## Get started

Read [Self-hosting](/docs/self-hosting) to deploy the server, then create your account at `/agents/`. Choose a repository and send your first task.

## Your workspace

The run page shows live messages, tool output, plans and diffs. Send follow-ups on the same run. Press Enter to send, or Shift+Enter for a new line. Configure scheduled agents and automatic pull-request creation on Automations. Open Settings to manage your profile photo, model providers, sessions and OpenID Connect.
