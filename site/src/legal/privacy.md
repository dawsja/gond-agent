# Privacy

Last updated: October 29, 2026

This Gond Agent instance is operated by its host administrator. Account details, sign-in sessions, run transcripts, images and usage are stored in the instance's local SQLite database.

## Code and models

Repository work runs in isolated workers. Requests to the configured model provider include the prompts and code needed for the task. GitHub receives branches and pull requests through the host's authenticated GitHub session.

## Control of data

The host administrator controls storage, backups, account registration and identity providers. Ask the administrator about retention, access, export or deletion of data. Gond Agent does not use your prompts or code to train models.
